════════════════════════════════════════
TAREA 1 — CLASIFICACIÓN DEL DOMINIO
════════════════════════════════════════
Clasifica el objetivo según el VERBO PRINCIPAL (no el tema):

- cognitiva: verbos de proceso mental
  (identificar, analizar, explicar, describir, reconocer,
  comprender, evaluar, distinguir, interpretar, aprender a...)

- psicomotriz: verbos de ejecución o procedimiento
  (aplicar, ejecutar, construir, demostrar, operar,
  manipular, realizar, utilizar, desarrollar [cuando implica
  hacer algo físico o procedimental]...)

- afectiva: verbos de actitud, valor o disposición
  (valorar, apreciar, respetar, comprometerse, reflexionar,
  tomar conciencia, ser consciente, asumir, adoptar...)

- general: cuando el objetivo nombra explícitamente
  resultados de más de un dominio

REGLA CRÍTICA: El dominio lo determina el VERBO PRINCIPAL,
no el contenido temático del objetivo.
  Correcto: "aplicar los principios de ISO 9001" = PSICOMOTRIZ
  Correcto: "valorar la importancia del trabajo en equipo" = AFECTIVO
  Correcto: "identificar los tipos de riesgo" = COGNITIVO

────────────────────────────────────────
REGLA DE CONTEXTO — VERBOS AMBIGUOS
────────────────────────────────────────
Algunos verbos pueden pertenecer a distintos dominios según
cómo se usen. Evalúa SIEMPRE el verbo junto con la frase
que indica el CÓMO (condición) antes de clasificar:

→ Si el verbo va acompañado de "mediante [instrumento /
  herramienta / formato / procedimiento]", clasifica como
  PSICOMOTRIZ, porque implica ejecutar un proceso con una
  herramienta concreta.

→ Si el verbo solo implica un proceso mental sin herramienta
  ni procedimiento descrito, clasifica como COGNITIVO.

Ejemplos del mismo verbo en dominios distintos:

  "diagnosticará la cultura organizacional mediante un
   formato de diagnóstico"
   → PSICOMOTRIZ (ejecuta una herramienta)

  "diagnosticará las causas del problema analizando
   la información"
   → COGNITIVO (proceso mental de análisis)

  "identificará los riesgos mediante una lista de
   verificación"
   → PSICOMOTRIZ (aplica un instrumento)

  "identificará los tipos de liderazgo según sus
   características"
   → COGNITIVO (proceso de clasificación mental)

────────────────────────────────────────
REGLA DE DESEMPATE — RESULTADO DECLARADO
────────────────────────────────────────
Si el texto incluye frases que declaran explícitamente
el tipo de resultado esperado, ese resultado manda
sobre el verbo:

  ✓ "contará con los conocimientos necesarios para..."
  ✓ "comprenderá los fundamentos de..."
  → Clasifica como COGNITIVO aunque el tema sea práctico.

  ✓ "ejecutará el procedimiento mediante..."
  ✓ "aplicará el formato de..."
  ✓ "actuará de acuerdo con los protocolos..."
  → Clasifica como PSICOMOTRIZ.

────────────────────────────────────────
REGLA DE COMPLEMENTARIEDAD
────────────────────────────────────────
Este objetivo debe:
  ✓ Abordar el MISMO TEMA que el cognitivo, pero desde
    la ejecución práctica, no desde el conocimiento.
  ✓ Usar un verbo diferente al del objetivo cognitivo.
  ✗ No repetir textualmente frases del objetivo cognitivo.
  ✗ No describir solo comprensión o conocimiento
    (eso ya lo cubre el objetivo cognitivo).

Si el objetivo psicomotriz es demasiado similar al
cognitivo, indícalo en el resumen.

════════════════════════════════════════
TAREA 2 — EVALUACIÓN ESTRUCTURAL
════════════════════════════════════════
Lee el texto COMPLETO antes de evaluar cada criterio.
Cada criterio es independiente: no penalices uno por
la ausencia de otro.

─────────────────────────────────────────
CRITERIO 1 — quien (QUIÉN aprende)
─────────────────────────────────────────
Cuenta como TRUE:
  ✓ "el participante", "los capacitandos", "el trabajador",
    "el colaborador", cualquier mención explícita del sujeto.
Marca FALSE solo si:
  ✗ No aparece ninguna referencia al sujeto en todo el texto.

─────────────────────────────────────────
CRITERIO 2 — cuando (CUÁNDO ocurre)
─────────────────────────────────────────
Cuenta como TRUE:
  ✓ "durante el curso", "al finalizar la capacitación",
    "al término de la sesión", "al concluir el módulo",
    "al finalizar la segunda unidad", "al terminar la unidad",
    cualquier referencia temporal incluyendo unidades o
    módulos específicos del curso.
Marca FALSE solo si:
  ✗ No existe ninguna frase temporal en todo el texto.

─────────────────────────────────────────
CRITERIO 3 — accion (QUÉ hace el participante)
─────────────────────────────────────────
Cuenta como TRUE:
  ✓ Cualquier verbo psicomotriz observable en infinitivo
    o futuro: "aplicará", "ejecutará", "elaborará",
    "construirá", "demostrará", "operará", "realizará",
    "utilizará", "actuará", "diagnosticará [con herramienta]",
    "identificará [mediante instrumento]"...
Marca FALSE solo si:
  ✗ No existe ningún verbo de acción observable.
NOTA: Si el verbo existe pero no corresponde al dominio
psicomotriz, marca accion TRUE de todas formas.
El error de dominio se reporta en coincide_con_seccion.

─────────────────────────────────────────
CRITERIO 4 — objeto (SOBRE QUÉ recae la acción)
─────────────────────────────────────────
Cuenta como TRUE:
  ✓ Cualquier complemento directo del verbo que describa
    el producto, actividad, herramienta, procedimiento o
    desempeño concreto que se ejecutará.
Marca FALSE solo si:
  ✗ El verbo no tiene objeto.

─────────────────────────────────────────
CRITERIO 5 — condicion (CÓMO o BAJO QUÉ circunstancias)
─────────────────────────────────────────
Cuenta como TRUE cualquiera de estas formas:
  ✓ "con base en...", "mediante...", "utilizando...",
  ✓ "siguiendo...", "con el principio de...", "a través de...",
  ✓ "empleando...", "bajo el enfoque de...", "de acuerdo con...",
  ✓ "conforme a...", "apoyándose en...", "conforme a la NOM...",
  ✓ "mediante herramientas de análisis", "usando el formato de...",
  ✓ "con instrumentos de evaluación"
Marca FALSE solo si:
  ✗ No existe ninguna frase que describa el cómo o contexto.

─────────────────────────────────────────
CRITERIO 6 — finalidad (PARA QUÉ sirve el aprendizaje)
─────────────────────────────────────────
Cuenta como TRUE cualquiera de estas formas:
  ✓ "con la finalidad de...", "para que...", "a fin de...",
  ✓ "con el propósito de...", "permitiéndole...", "logrando...",
  ✓ "con el objetivo de...", "para identificar...",
  ✓ "para contribuir a...", "lo que le permitirá...",
  ✓ Frase final con "para" aunque encadene dos propósitos.
Marca FALSE solo si:
  ✗ El texto termina sin ninguna referencia al para qué.

════════════════════════════════════════
REGLAS DEL CAMPO "resumen"
════════════════════════════════════════
Infiere el tema del curso a partir del texto evaluado
y úsalo en todas las sugerencias. Nunca uses ejemplos
genéricos desconectados del tema real.

Usa exactamente uno de estos cuatro casos:

─────────────────────────────────────────
CASO A — Todos los criterios TRUE, coincide_con_seccion TRUE
y relacion_con_anterior TRUE:
─────────────────────────────────────────
"✅ El objetivo cumple con todos los criterios EC0217.01.
Dominio psicomotriz confirmado."

─────────────────────────────────────────
CASO B — Exactamente UN criterio en false:
─────────────────────────────────────────
"❌ [CRITERIO EN MAYÚSCULAS]: [cita textual del fragmento
más cercano entre comillas, o 'no encontrado en el texto'].
[Una oración explicando por qué no cumple.]

💡 Para el tema de [tema inferido], podrías completar
tu objetivo con una frase como:
  Opción A: '[frase concreta adaptada al tema del curso]'
  Opción B: '[frase alternativa con diferente redacción]'

¿Cuál se acerca más a lo que quieres expresar?"

─────────────────────────────────────────
CASO C — Más de un criterio en false:
─────────────────────────────────────────
Reporta ÚNICAMENTE el primer criterio en false según
este orden de prioridad:
  1. quien → 2. cuando → 3. accion → 4. objeto →
  5. condicion → 6. finalidad

Usa el mismo formato del Caso B para ese único criterio,
y agrega al final:
"(Una vez que corrijas esto, revisaremos el siguiente
elemento.)"

─────────────────────────────────────────
CASO D — coincide_con_seccion es false:
─────────────────────────────────────────

SOLO aplica este caso si tipo_detectado NO es "psicomotriz".
Si tipo_detectado ES "psicomotriz" pero hay incoherencia 
temática con el objetivo anterior, usa el Caso E, no el Caso D.

Reporta SOLO el error de tipo, sin evaluar criterios
estructurales:

"⚠️ El verbo '[verbo principal]' en este objetivo
corresponde al dominio [tipo_detectado], no al psicomotriz.

[Una oración explicando la diferencia práctica entre
ambos dominios, usando el tema del curso.]

💡 Si quieres que este sea un objetivo psicomotriz,
considera cambiar el verbo. Para el tema de [tema inferido],
un verbo psicomotriz podría ser:
  Opción A: '[verbo psicomotriz + objeto aplicado al tema]'
  Opción B: '[verbo psicomotriz alternativo + objeto]'

¿El resultado que buscas es que el participante
ejecute / aplique / demuestre [tema inferido]?"

─────────────────────────────────────────
CASO E — relacion_con_anterior es false:
─────────────────────────────────────────
Añade esta nota AL FINAL del resumen (después del caso
que corresponda):

un tema diferente al objetivo cognitivo ya aceptado.
El cognitivo trata sobre [tema del cognitivo]; asegúrate
de que el psicomotriz sea la práctica de ese mismo tema."
